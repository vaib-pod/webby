Privacy, consent & control

WEBBY works offline by default. AI analysis requires a separate, explicit action and an optional local backend.

AI analysis consent

Only a structural summary containing roles, tags, issue types and coarse page category is sent. No page text, form values, raw HTML, browsing history or full URL. The local backend can forward the summary to a configured AI provider.

Allow AI requests

Opt in to enable the Analyze button in the extension.

The AI feature is blocked automatically on pages with password/payment inputs or sensitive pathnames. AI outputs are validated against a fixed action allowlist.

AI server connection

The API runs on your computer and keeps the key out of the extension.

http://127.0.0.1:3001

Without a configured AI key, the backend returns clearly labeled rule-based fallback recommendations.

Delete all WEBBY local data

Erases your profile, site customizations, feedback history, analysis log and AI consent from this browser. This cannot be undone.
